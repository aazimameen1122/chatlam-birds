# Chatlam Birds (چھاتلَم وؠٹلینڈ پامپوٗر)

A clean, responsive, and authentic photographic guide to the birds of **Chatlam Wetland Reserve** in Pampore (Pulwama, Kashmir).

This website displays all **46 verified bird species** recorded at Chatlam, featuring:
- Official English Common Name
- Scientific Binomial Name
- Authentic Traditional Kashmiri Name in both Nastaliq script and Roman spelling (e.g. *Pind*, *Mong*, *Broku*, *Bor*, *Brag*, *Goi*, *Anz*, *Niluj / Thuj*, *Sukh Pachan*, *Kues*, *Honk*, *Shierene Budun*, *Budun*, *Noer*, *Thauther*, *Khrokh*, *Tsarow*, *Harwat*, *Tsakaow*, *Gagur*, *Goda grad / Loz*, *Gaunt*, *Gred*, *Hillaw*, *Grettu / Grallu*, *Gillu*, *Tech*, *Kollur / Kavput*, *Gund Kaw*, *Gug / Gugu*, *Kola Katij*, *Hatatut*, *Greese Maharaz*, *Chah*, *Kola Kavin*, *Zar Batchi*, *Longzeyat*, *Krew / Kresh*, *Jungli Kotur*, *Kukil*, *Wan Kukil*, *Shoga*, *Tota*, *Hor Kuk*, *Kola Tonch*, *Bud Kola Tonch*)
- High-resolution photographic reference from Wikimedia Commons
- Field identification notes and habits
- Direct links to full Wikipedia articles
- Photographer credits and Creative Commons licenses

## 🚀 How to Run the Website

### Option 1: Double-Click Launcher (Windows)
Double-click `start_website.bat` in the project folder to start the local server and open the site in your browser.

### Option 2: Local Server via Terminal
In PowerShell or Command Prompt, run:
```powershell
npm start
```
or:
```powershell
python -m http.server 8080 --bind 127.0.0.1
```
Then navigate to:
```
http://127.0.0.1:8080
```

### Option 3: Direct File Open
Open `index.html` directly in any web browser.

## 🔍 Features
- **Instant Search**: Search by English name, scientific name, or Kashmiri name (e.g., search "Pind", "Honk", "Niluj", "Brag", or "پِنٛڈ").
- **Category Filter**: Filter between Ducks & Geese, Herons, Waders & Rails, Shorebirds & Snipes, Birds of Prey, Kingfishers, and Pigeons & Doves.
- **View Toggle**: Switch between **Photo Cards View** and **Complete Reference Table**.
- **Detail Modal**: Click any bird card to open the large photo, full field description, and Wikipedia article.
- **Theme Toggle**: Switch between clean Light and Dark modes.
